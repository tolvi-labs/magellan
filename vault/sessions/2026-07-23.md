## [10:27] Session — Magellan born: vault initiated, genesis decision, README, schematic plan

**Tickets:** none

### What happened
- Stood up Magellan as a new Tolvi tool, born from the Guild reframe (Guild sheds plan-authoring; see guild vault [[2026-07-23-guild-sheds-plan-authoring-to-magellan]]). Magellan is the executor-agnostic execution-optimized plan compiler: it takes Guild's approved brief and compiles it into a decomposed, context-compiled task DAG that Forge, Claude Code, or a cloud agent can each execute.
- Wrote the genesis decision [[2026-07-23-magellan-execution-optimized-plan-compiler]]: compiler not approach-chooser; per-task context compilation as the accuracy↔cost resolver; decomposition + context in one pass; output = a Forge `tasks.json` superset with a per-task `context` field; accuracy-first with cost minimized only where it does not cost accuracy; structural-correctness-only (enforcement stays with Bastion and Canary); optional stage. It also records the new suite shape: Vault → Guild → Bastion → Magellan → Forge.
- Initiated the vault per standard (`.vault-meta.json` + `decisions/`, `sessions/`, `patterns/`), rewrote the stub README to the compiler identity, and wrote `docs/PLAN.md` as a schematic 4-phase build plan (output schema → decomposition → context compilation → executor adapters) with verify conditions, riskiest assumptions, and boundaries.
